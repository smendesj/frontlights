# Redesenho do Frontlights (22/10/2026)

Evidência da análise que originou o redesenho: o retro de 13 sessões reais em três projetos consumidores,
as nove análises por lente, as 69 propostas julgadas e a síntese com números antes e depois.

- `redesenho.html`: a página visual (abra no navegador): custo por etapa, fluxo novo, janelas do Chrome,
  scripts novos, roteiro de 11 issues.
- `proposta.md`: a proposta completa, usada como especificação das issues do redesenho (seção 8) e da
  propriedade de arquivos entre elas (seção 8.1).

Os nomes de projeto, pessoas, sessões e caminhos locais foram trocados por marcadores genéricos.
Os números são agregados das sessões; nenhuma saída de sessão foi copiada.
